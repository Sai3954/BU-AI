    Overview

    Retrieval-augmented generation (RAG)

    The AI never answers from memory. For every question it first finds the relevant official pages, then writes an answer using only those pages, then checks the answer against them before the student sees it.

    Boxes marked v2 are new in the stronger version being tested now.
