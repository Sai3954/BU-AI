How BU AI answers a question

Five simple steps. Pick a question and press Play to watch it happen.

1
📚

Reads the website

Ahead of time, BU AI reads Belhaven's public web pages and PDFs, like a librarian building a catalog.

2
💬

Student asks

A student types a question in everyday words. Names and ID numbers are removed first.

3
🔎

Finds the right pages

It looks for the official pages that answer it, and picks pages that fit the student (for example, doctoral rules for a DBA student).

4
✍️

Writes the answer

The AI writes a short answer using only those pages, with a link for every fact.

5
✅

Double-checks

Before the student sees it, every number is checked against the page. Warnings are added when needed.

For IT staff: technical details
  • Collection: polite crawler (robots.txt, about 1 page per second, public belhaven.edu only, sitemap discovery). Pages are split into short passages tagged by topic, audience, level and catalog year.
  • Search: hybrid retrieval: BM25 keyword index plus semantic embeddings (open model running on our server), fused with reciprocal rank fusion. Level-aware, newest-catalog-first ranking and an off-topic guard.
  • Answer: large language model (Anthropic Claude) instructed to answer only from numbered sources, with citations.
  • Checks: personal details removed before search and logging; citation and figure verification; conflict detection between sources; DSO and crisis rules; daily usage caps.
  • Stack: Next.js website, Python FastAPI service, PostgreSQL, Docker. An automated test suite runs on every change.
